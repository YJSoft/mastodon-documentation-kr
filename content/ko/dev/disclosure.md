마스토돈의 보안 취약점(허용되어서는 안 되는 일을 가능하게 만드는 버그)을 발견했다고 생각한다면 [GitHub에서 보안 이슈를 열거나](https://github.com/mastodon/mastodon/security/advisories/new) **security@joinmastodon.org**로 보고서를 보내 주세요.

현재는 버그 바운티 프로그램을 제공하지 않습니다.

마스토돈 사용자를 더 큰 위험에 노출하지 않으면서 문제의 수정 사항을 공개할 시간을 확보할 수 있도록, 이러한 문제를 공개 GitHub 이슈나 다른 공개 공간에 보고해서는 *안 됩니다*.

{{< hint style="info" >}}
“마스토돈의 취약점”이란 GitHub의 주 소스 코드 저장소를 통해 배포되는 코드의 취약점을 뜻합니다. 특정 설치 환경에만 해당하는 취약점(예: 잘못된 구성)은 저희가 아니라 해당 설치 환경의 소유자에게 보고해야 합니다.
{{< /hint >}}
