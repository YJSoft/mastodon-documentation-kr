## 날짜와 시각 {#datetime}

“날짜와 시각”은 시간상의 한 순간을 지정합니다.

날짜와 시각의 문자열 표현은 [RFC3339 절 5.6](https://www.rfc-editor.org/rfc/rfc3339#section-5.6)에 정의된 “인터넷 날짜/시각 형식”을 사용합니다.

요약하면 다음 필수 구성 요소로 이루어집니다.

```text
[YYYY]-[MM]-[DD]T[hh]:[mm]:[ss].[s][TZD]
```

각 부분의 의미는 다음과 같습니다.

- `[YYYY]` = 네 자리 연도
- `[MM]`   = 두 자리 월(01=1월 등)
- `[DD]`   = 두 자리 일(01부터 31까지)
- `[hh]`   = 두 자리 시(00부터 23까지, 24는 허용하지 않음)
- `[mm]`   = 두 자리 분(00부터 59까지)
- `[ss]`   = 두 자리 초(00부터 60까지)
- `[s]`    = 초의 소수 부분을 나타내는 하나 이상의 숫자
- `[TZD]`  = 시간대 지정자(UTC는 `Z`, UTC와의 차이는 `+[hh]:[mm]` 또는 `-[hh]:[mm]`)

예를 들어 `1994-11-05T13:15:30.000Z`입니다(`1994-11-05T08:15:30-05:00`과 같음).

완전한 [ABNF 문법](https://www.rfc-editor.org/rfc/rfc2234)은 [RFC3339 절 5.6](https://www.rfc-editor.org/rfc/rfc3339#section-5.6)을 참고하세요.

### 상호 운용성 {#interoperability}

- 날짜와 시각 부분은 항상 대문자 `T`로 구분합니다(소문자나 공백이 아님).
- 시간대 지정자 `Z`는 항상 대문자이며 소문자를 사용하지 않습니다.
- 초의 소수 부분(`[s]`)은 최소 한 자리에서 최대 세 자리 숫자로 표현합니다.
- 필드는 정밀도가 낮아도 날짜와 시각으로 표시될 수 있습니다. 예를 들어 서버가 값을 해당 날짜의 자정으로 제한할 수 있습니다.

## 날짜 {#date}

“날짜”는 활동이 발생한 UTC 기준 달력 날짜를 지정합니다.

날짜의 문자열 표현은 날짜와 시각 표현의 국제 표준 ISO 8601에서 완전한 확장 달력 날짜 표현(절 5.2.1.1)을 사용합니다. [W3C 날짜 및 시각 형식](https://www.w3.org/TR/NOTE-datetime)의 “완전한 날짜” 형식이기도 합니다.

필수 구성 요소는 다음과 같습니다.

```text
[YYYY]-[MM]-[DD]
```

- `[YYYY]` = 네 자리 연도
- `[MM]`   = 두 자리 월(01=1월 등)
- `[DD]`   = 두 자리 일(01부터 31까지)

### 상호 운용성 {#interoperability-1}

- 연도, 월, 일 구성 요소는 항상 `-`로 구분합니다.
