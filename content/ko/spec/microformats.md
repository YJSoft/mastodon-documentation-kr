## 마이크로포맷이란 무엇인가요? {#intro}

[Microformats 2.0](https://microformats.io/)은 HTML 문서 안에 직접 메타데이터를 삽입하는 표준입니다. 읽기 전용 용도로 API를 사용하는 대신, 웹페이지의 특정 CSS 클래스를 분석하여 페이지를 보는 것만으로 이미 가져온 정보를 추출할 수 있습니다. 같은 정보를 API에서 별도로 요청할 필요가 없습니다. 마이크로포맷 클래스를 사용하면 웹페이지의 데이터를 의미에 따라 분석할 수 있으며, 이 데이터로 피드, 카드, 기타 표현을 생성할 수 있습니다.

## 마이크로포맷 클래스 {#classes}

모든 마이크로포맷 클래스에는 접두사가 있습니다. 접두사는 계층과 무관하게 요소의 유형을 나타냅니다. 다음은 마스토돈 코드베이스에서 사용하는 마이크로포맷 클래스입니다.

### 루트 요소 (`h-*`) {#h}

#### `h-card` {#h-card}

사람이나 조직을 나타냅니다. 표시 이름, 사용자명, 아바타를 감싸는 컨테이너에 부착합니다. 멘션에도 부착합니다.

### 일반 텍스트 속성 (`p-*`) {#p}

#### `p-name` {#p-name}

사람이나 조직의 일반 텍스트 이름을 나타냅니다. 표시 이름에 부착합니다.

### URL 속성 (`u-*`) {#u}

#### `u-url` {#u-url}

`h-card` 안에서 프로필 고유 링크를 나타냅니다. 표시 이름 링크에 부착합니다.

## 추가 클래스 {#mastodon}

이 요소는 마스토돈이 메타데이터 분석을 위해 부착하지만, 기술적으로 Microformats 어휘에 속하지는 않습니다.

### `mention` {#mention}

API의 관련 멘션 데이터로 링크를 앱 안에서 열어야 함을 나타냅니다.

### `hashtag` {#hashtag}

API의 관련 해시태그 데이터로 링크를 앱 안에서 열어야 함을 나타냅니다.
