## 서버 선택하기 {#picker}

이메일 제공자를 고르거나 World of Warcraft에서 새 캐릭터를 만들 서버를 고르듯이, 가입할 서버를 선택해야 합니다. 선택한 서버는 계정과 프로필, 홈 피드를 제공하는 서비스 제공자가 됩니다.

{{< hint style="info" >}}
[joinmastodon.org에서 주제별·언어별 서버 목록을 살펴볼 수 있습니다](https://joinmastodon.org/#getting-started).
{{< /hint >}}

### 서버의 정책 이해하기 {#tos}

가입하기 전에 해당 서비스의 정책과 이용약관을 이해하는 것이 중요합니다. 마스토돈 서버는 보통 `/about/more` 페이지에 정책을 게시합니다. 로그아웃 상태에서 첫 화면의 “더 알아보기”를 클릭하면 찾을 수 있습니다.

### 가입 방식 {#signup}

마스토돈 서버 관리자는 자유 가입, 초대 가입, 승인제 가입 중 하나를 선택할 수 있습니다.

#### 자유 가입 {#open}

일부 서버에서는 바로 가입할 수 있습니다. 가입 양식에 사용자명, 이메일 주소, 비밀번호를 입력하면 계정을 사용할 수 있습니다.

#### 서버 초대 {#invite}

일부 서버는 일반 가입 양식을 비활성화하고, 생성하여 공유한 초대 링크로만 가입을 받습니다.

#### 승인제 가입 {#approval}

일부 서버에서는 가입 양식에 해당 서버에 가입하려는 이유를 추가로 작성해야 합니다. 양식을 제출한 뒤 중재자의 승인을 받아야 계정을 사용할 수 있습니다.

## 사용자명과 도메인 {#address}

마스토돈의 사용자명은 두 부분으로 구성됩니다.

* 로컬 사용자명. 예: `alice`
* 서버의 도메인. 예: `example.com`

이메일 주소와 같은 방식입니다. 편의를 위해 같은 서버에 있는 사람을 지칭할 때는 두 번째 부분을 생략할 수 있습니다. 하지만 다른 사람에게 사용자명을 알려줄 때는 도메인까지 포함해야 쉽게 찾을 수 있다는 점을 기억하세요.

| 사용자명 공유 예시 |  |
| :--- | :--- |
| 마스토돈의 `@alice`입니다! | 잘못된 예 |
| 마스토돈의 `@alice@example.com`입니다! | 올바른 예 |
| 마스토돈의 https://example.com/@alice 입니다! | 올바른 예 |

마스토돈 검색창에서는 위와 같은 주소나 프로필 링크로 사람을 찾을 수 있으므로, 원한다면 프로필 링크를 공유해도 됩니다.

서로 다른 서버에 같은 사용자명을 등록할 _수 있습니다_. 모든 서버의 사용자명을 미리 확보하는 방법은 없습니다. 이메일과 마찬가지로 `alice@outlook.com`, `alice@gmail.com`, `alice@yahoo.com`이 같은 사람이라고 생각해서는 안 됩니다.
