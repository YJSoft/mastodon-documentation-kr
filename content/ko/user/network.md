## 실시간 피드에서 콘텐츠 둘러보기 {#timelines}

{{< figure src="assets/timeline.png" width="70%" caption="다른 서버의 게시물이 들어오는 실시간 피드" >}}

마스토돈은 흥미로운 콘텐츠를 발견할 수 있도록 공개 게시물을 둘러보는 기능을 제공합니다. 모든 서버가 하나의 전역 상태를 공유하지는 않으므로 _모든_ 공개 게시물을 한 번에 볼 수는 없습니다. **실시간 피드 > 다른 서버**에서는 연합우주 곳곳의 공개 게시물을 볼 수 있습니다. 서버가 [여러](#fetching-replies) [방법](#search)으로 알게 된 게시물이 표시되며, 대부분은 내 서버의 다른 사용자가 팔로우하는 계정의 게시물입니다.

실시간 피드에서 내 서버에 작성된 공개 게시물만 보도록 필터링할 수도 있습니다.

## 게시물에 반응하기 {#actions}

{{< figure src="assets/status.png" width="70%" caption="타임라인의 게시물을 클릭하면 상세 화면을 열 수 있습니다" >}}

타임라인에서 바로 게시물에 반응하거나, 게시물을 클릭하여 정확한 작성 시각, 반응 수, 스레드의 답글 등 추가 정보가 있는 상세 화면을 열 수 있습니다. 게시물에서 다음 작업을 할 수 있습니다.

* 화살표 아이콘을 클릭하여 **답글**을 작성합니다. 답글은 원래 게시물 아래의 스레드에 표시됩니다.
* 순환하는 화살표 아이콘을 클릭하여 **부스트**합니다. 게시물이 내 프로필에 다시 공유됩니다.
* **부스트** 버튼 메뉴에서 **인용**을 선택합니다. [인용 게시물에 대해 더 알아보기](../quote-posts).
* 별 아이콘을 클릭하여 **좋아요**를 표시합니다. 게시물이 내 좋아요 목록에 추가되고 작성자에게 좋아요 알림이 전달됩니다.
* 리본 아이콘을 클릭하여 **북마크**합니다. 알림을 보내지 않고 나만 볼 수 있는 북마크 목록에 추가됩니다.
* 말줄임표 아이콘을 클릭하여 추가 옵션 **메뉴**를 엽니다.

### 답글 가져오기 {#fetching-replies}

게시물의 상세 화면을 열면[^expanded], [관련 기능이 활성화되어 있는 경우]({{< ref "/admin/config#fetch-all-replies" >}}) 내 서버가 아직 모르는 답글을 다른 서버에서 가져오려고 시도합니다. 대화 스레드에 참여한 각 서버를 확인하여 누락된 답글을 수집하므로, 답글이 많거나 내 서버에서 처음 보는 게시물이라면 시간이 걸릴 수 있습니다. 모든 답글이 보이지 않는 것 같다면 잠시 뒤 새로고침해 보세요.[^retrigger]

팔로워 전용 게시물, 개인 멘션, [인증을 요구하는]({{< ref "/admin/config#authorized_fetch" >}}) 서버의 게시물 등 일부 답글은 가져오지 않습니다. 다만 나 또는 내 서버의 다른 사용자가 이미 해당 작성자를 팔로우한다면 예외입니다.

게시물을 [검색](#search)한 다음 상세 화면을 열면 답글 트리를 내 서버로 “가져오는” 효과가 있습니다. 이를 통해 나와 같은 서버의 다른 사용자들이 연합우주의 새로운 사람들과 다양한 존재들을 만날 수 있습니다!

[^expanded]: 여기서 상세 화면을 연다는 것은 게시물을 클릭하여 자세히 보는 것을 의미합니다. 콘텐츠 경고를 펼치거나 게시물 필터를 해제하는 것을 뜻하지는 않습니다.

[^retrigger]: 일정 대기 시간 안에는 새로고침해도 가져오기 작업이 다시 실행되지 않으므로, 너무 자주 요청할까 걱정하지 않아도 됩니다!

## 알림 {#notifications}

{{< figure src="assets/notifications.png" width="70%" caption="묶어 보기 기능을 활성화한 알림 열" >}}

다른 사람이 나 또는 내 게시물과 상호작용하면 이벤트 종류에 따라 알림을 받습니다. 알림 열에서 모든 알림을 함께 보거나 특정 종류만 필터링할 수 있습니다.

* **멘션:** 다른 사람이 게시물에서 나를 멘션했을 때 받습니다.
* **좋아요:** 다른 사람이 내 게시물에 좋아요를 표시했을 때 받습니다.
* **부스트:** 다른 사람이 내 게시물을 부스트했을 때 받습니다.
* **투표:** 내가 참여하거나 만든 투표가 종료되면 받습니다.
* **게시물:** 게시물 알림을 켜 둔 사용자가 글을 올리면 받습니다.
* **팔로우:** 다른 사람이 내 프로필을 팔로우하면 받습니다.

읽지 않은 알림이 있으면 열의 머리글에 체크 표시가 나타납니다. 클릭하면 알림을 읽음으로 표시합니다.

## 프로필 팔로우하기 {#follow}

{{< figure src="assets/profile.png" width="70%" caption="팔로우 버튼이 표시된 프로필 카드" >}}

내 서버의 웹 화면이나 모바일 앱 등 내가 사용하는 앱에서 다른 사용자를 발견했다면 “팔로우”를 클릭하면 됩니다. 같은 서버에 있든 다른 서버에 있든 방식은 같습니다.

내 앱 밖에서 다른 서버에 있는 공개 프로필을 발견했다면 한 가지 문제가 있습니다. 그 서버에서는 나를 익명 방문자로 인식합니다. 걱정할 필요는 없습니다! 프로필이나 게시물의 URL을 복사한 다음 내 앱의 검색창에 붙여 넣으세요.

다른 마스토돈 서버의 공개 페이지를 보고 있다면 [외부에서 마스토돈 사용하기](../external/#interact)를 참고하세요.

## 게시물 알림 켜기 {#bell}

{{< figure src="assets/bell.png" width="70%" caption="팔로우 중인 프로필의 예시" >}}

팔로우 중인 사람이 글을 올릴 때마다 알림을 받을 수도 있습니다. 종 모양 아이콘을 클릭하면 이 기능이 켜집니다.

## 검색 {#search}

{{< figure src="assets/search.png" width="50%" caption="검색 조건 옵션을 펼친 검색 기능. 각 옵션은 아래 접두사 설명을 참고하세요" >}}

로그인한 사용자는 마스토돈의 기본 검색으로 특정 해시태그가 포함된 게시물을 찾거나, URL이나 주소를 알고 있는 사용자와 게시물을 직접 불러올 수 있습니다. 검색어를 입력하면 사용자명 또는 표시 이름에 해당 검색어가 포함된 프로필과, 검색어와 일치하거나 검색어를 포함하는 해시태그가 표시됩니다. 원격 게시물이나 계정의 전체 URL을 검색하면 데이터베이스에 없는 경우 서버가 이를 가져와 내 서버에서 볼 수 있게 합니다.

{{< figure src="assets/direct-url.png" width="70%" caption="URL로 직접 불러온 게시물의 예시" >}}

{{< figure src="assets/search-accounts.png" width="70%" caption="&quot;arstechnica&quot; 검색 결과. 도메인으로 인증된 계정도 포함되어 있습니다" >}}

{{< figure src="assets/search-hashtags.png" width="70%" caption="&quot;friday&quot;를 검색했을 때 나오는 해시태그 예시" >}}

관리자는 선택적으로 전문 검색 기능을 설치할 수 있습니다. 마스토돈의 전문 검색을 사용하면 로그인한 사용자가 자신의 게시물, 좋아요한 게시물, 북마크, 자신에 대한 멘션에서 검색할 수 있습니다. 전문 검색은 안전을 위해 제한됩니다. 데이터베이스 전체의 모든 텍스트를 검색할 수는 없습니다. 논쟁적인 표현을 검색해 다른 사람을 찾아내 괴롭히는 일을 막기 위한 조치입니다.

다음 검색 연산자를 지원합니다.

* **"exact phrases"**: 따옴표 안의 구문과 정확히 일치하는 내용을 찾습니다. 예를 들어 `"look at my cluckers"`로 해당 표현을 그대로 사용한 게시물을 찾을 수 있습니다.
* **-exclude**: 빼기 기호 뒤의 단어를 제외합니다. 예를 들어 `animals -cats`로 animals가 포함된 게시물 중 cats가 포함된 게시물을 제외할 수 있습니다.
* **+include**: 더하기 기호 뒤의 단어를 반드시 포함합니다. 예를 들어 `cat +dog`로 cat과 dog가 모두 포함된 게시물을 찾을 수 있습니다.

다음 `prefix:value` 형식도 지원합니다.

* `has:` (`media`, `poll`, `embed`): 지정한 첨부 유형이 있는 게시물
* `is:` (`reply`, `sensitive`): 답글이거나 민감한 콘텐츠로 표시된 게시물
* `language:` (`{language_code}`): [ISO 639-1 언어 코드](https://en.wikipedia.org/wiki/List_of_ISO_639_language_codes)로 지정한 언어의 게시물
* `from:` (`@{username}`, `@{username}@{domain}`, `me`): 지정한 작성자의 게시물
* `before:` (`{date}`): "`2025-03-01`"처럼 ISO8601 형식으로 지정한 날짜 이전의 게시물. 계정에 시간대가 설정되어 있으면 해당 시간대를, 그렇지 않으면 UTC를 사용합니다.
* `after:` (`{date}`): ISO8601 형식으로 지정한 날짜 이후의 게시물
* `during:` (`{date}`): ISO8601 형식으로 지정한 날짜 동안의 게시물
* `in:` (`library`, `public`): `library`는 좋아요, 부스트, 북마크 등 어떤 방식으로든 내가 상호작용한 게시물 모음입니다. `public`은 전역 전문 검색 색인입니다. 생략하면 기본적으로 둘 다 검색합니다.

각 조건은 텍스트 검색과 함께 사용할 수 있습니다. 예를 들어 내가 쓴 미확인 생물 관련 게시물은 `from:me "cryptids"`로 찾을 수 있습니다.

접두사를 여러 개 조합할 수 있지만 `AND`로 결합되므로, 여러 언어 중 하나에 해당하는 게시물을 한 번에 검색하는 용도로는 사용할 수 없습니다.

문자열 검색처럼 접두사 앞에 `-`를 붙여 조건을 제외할 수 있습니다. 예를 들어 다른 사람이 쓴 미확인 생물 관련 게시물은 `-from:me "cryptids"`로 검색할 수 있습니다.

## 개인 멘션 {#private}

{{< figure src="assets/dm-column.png" width="70%" caption="개인 멘션이 포함된 대화 목록" >}}

마스토돈의 개인 멘션은 공개 범위가 “멘션된 사용자만”으로 설정된 게시물입니다. 공개 범위는 게시물마다 선택하므로 같은 스레드에서도 이후 게시물의 공개 범위를 바꿀 수 있습니다. 개인 멘션 열에는 현재 멘션 전용 게시물이 포함된 모든 대화가 표시됩니다. 대화를 클릭하면 해당 스레드가 열립니다.

## 리스트 타임라인 {#lists}

리스트는 홈 타임라인의 일부를 따로 모은 것입니다. 리스트를 만들고 이름을 붙인 다음 팔로우 중인 사용자를 추가할 수 있습니다.

{{< figure src="assets/lists.png" width="70%" caption="리스트 목록" >}}

리스트를 열면 해당 리스트의 타임라인이 표시됩니다. 리스트 구성원의 게시물과, 나 또는 다른 리스트 구성원에게 보낸 답글만 포함됩니다. 내가 팔로우하는 모든 사람에게 보낸 답글을 표시하거나 답글을 전혀 표시하지 않도록 바꿀 수도 있습니다.

## 외부 구독용 피드 {#syndication}

모든 계정과 태그 페이지는 다른 플랫폼에서 구독할 수 있도록 RSS 피드를 제공합니다. 해당 페이지에서 피드를 자동으로 발견할 수 있습니다.

## 번역 {#translation}

계정에 설정된 이해 가능한 언어와 다른 언어로 된 게시물에는 본문 옆에 “번역” 버튼이 나타납니다. 버튼을 클릭하면 서버에 번역을 요청하고 본문을 번역 결과로 바꿉니다. 서버에 번역 서비스가 설정되어 있어야 하므로 모든 서버에서 사용할 수 있는 기능은 아닙니다.
