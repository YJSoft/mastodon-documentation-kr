## 게시물 필터링 {#filters}

특정 단어나 구문이 포함된 게시물을 자동으로 숨기도록 필터링할 수 있습니다.

{{< figure src="assets/filter-list.png" width="70%" caption="여러 적용 범위와 키워드에 대해 활성화된 필터 예시" >}}

**환경설정** &gt; **필터**에서 필터를 만들고 관리할 수 있습니다. “새 필터 추가” 버튼으로 필터를 만들고, 기존 필터를 수정하거나 삭제할 수 있습니다. 기존 필터는 표에 요약되어 표시됩니다.

{{< figure src="assets/filter-edit.png" width="70%" caption="필터에 만료 시간, 적용 범위, 서버 측 숨김 옵션과 단어 경계 조건을 설정할 수 있습니다" >}}

### 키워드 또는 구문 {#filter-phrase}

일치 여부를 확인할 문자열입니다. 콘텐츠 경고(CW), 미디어 설명, 투표 선택지를 포함한 게시물 내용에서 검색합니다.

### 만료 시간 {#filter-expire}

원한다면 일정 시간 동안만 필터를 적용할 수 있습니다. 만료된 필터는 자동으로 삭제되지 않으며, 새 만료 시간을 설정하거나 “만료하지 않음”으로 바꾸면 다시 활성화됩니다.

### 필터 적용 범위 {#filter-context}

필터를 적용할 위치를 선택하세요.

* 홈 타임라인과 리스트: 일치하는 게시물을 홈 피드와 리스트에서 제거합니다.
* 알림: 일치하는 알림을 표시하지 않습니다.
* 공개 타임라인: 일치하는 게시물을 로컬·연합 타임라인에 표시하지 않습니다.
* 대화: 일치하는 게시물을 스레드와 상세 화면에서 숨깁니다.
* 프로필: 일치하는 게시물을 프로필 화면에서 숨깁니다.

### 완전히 숨기기 {#filter-hide}

필터링은 보통 클라이언트에서 이루어지므로 필터를 끄면 숨겨졌던 게시물이 다시 보입니다. 하지만 “완전히 숨기기”를 켜면 일치하는 게시물이 완전히 사라지고 홈이나 알림에 전달되지 않습니다.

### 단어 전체 일치 {#filter-whole}

일반적으로 필터는 지정한 문자열이 단어 중간에 있더라도 포함되기만 하면 적용됩니다. “단어 전체 일치”를 켜면 키워드 양쪽에 공백이나 영숫자가 아닌 문자가 있을 때만 적용됩니다.

## 사용자별 조치 {#blocking-and-muting}

{{< figure src="assets/profile-dropdown.png" width="70%" caption="다양한 작업을 제공하는 프로필 펼침 메뉴" >}}

### 부스트 숨기기 {#hide-boosts}

특정 사용자의 부스트를 숨기면 홈 피드에 그 사용자가 부스트한 게시물이 표시되지 않습니다. 현재 팔로우 중인 사용자에게만 이 옵션이 나타납니다.

### 인용 게시물 {#quote-posts}

다른 사용자가 원하지 않는 방식으로 내 게시물을 인용했다면 [인용된 내 게시물을 제거](../quote-posts#remove)할 수 있습니다.

### 뮤트 {#mute}

뮤트할 때 해당 사용자의 알림도 뮤트할지 선택할 수 있습니다. 알림은 뮤트하지 않고 사용자만 뮤트하면 다음과 같이 보이지 않게 됩니다.

* 홈 피드에 해당 사용자가 표시되지 않습니다.
* 다른 사람이 해당 사용자를 부스트한 게시물이 표시되지 않습니다.
* 다른 사람이 해당 사용자를 멘션한 게시물이 표시되지 않습니다.
* 공개 타임라인에 해당 사용자가 표시되지 않습니다.

알림도 뮤트하면 해당 사용자의 알림도 표시되지 않습니다.

뮤트 기간을 지정하면 기간이 끝난 뒤 자동으로 해제됩니다.

상대방은 자신이 뮤트되었는지 알 수 없습니다.

### 차단 {#block}

차단하면 해당 사용자가 보이지 않게 됩니다.

* 팔로우 중이었다면 팔로우를 취소합니다.
* 홈 피드에 해당 사용자가 표시되지 않습니다.
* 다른 사람이 해당 사용자를 부스트한 게시물이 표시되지 않습니다.
* 다른 사람이 해당 사용자를 멘션한 게시물이 표시되지 않습니다.
* 공개 타임라인에 해당 사용자가 표시되지 않습니다.
* 해당 사용자의 알림이 표시되지 않습니다.

차단된 사용자에게는 다음과 같은 변화도 생깁니다.

* 나에 대한 팔로우가 강제로 취소됩니다.
* 나를 팔로우할 수 없습니다.
* 다른 사람이 내 게시물을 부스트한 것이 보이지 않습니다.
* 공개 타임라인에서 내가 보이지 않습니다.

같은 서버의 사용자를 차단했다면 그 사용자는 로그인한 상태에서 내 프로필의 게시물을 볼 수 없습니다.

### 서버 전체 숨기기 {#block-domain}

{{< figure src="assets/block-domain.png" width="70%" caption="도메인 전체 차단 예시" >}}

서버 전체를 차단하면 다음과 같이 됩니다.

* 공개 타임라인에 해당 서버의 게시물이 표시되지 않습니다.
* 홈 피드에 다른 사람이 해당 서버의 게시물을 부스트한 것이 표시되지 않습니다.
* 해당 서버의 알림이 표시되지 않습니다.
* 해당 서버에 있던 내 팔로워를 잃게 됩니다.

## 문제가 있는 콘텐츠를 중재자에게 신고하기 {#report}

{{< figure src="assets/report-modal.png" width="70%" caption="게시물 선택, 설명 추가와 신고 전달이 가능한 신고 대화상자" >}}

서버의 규칙을 위반하는 게시물이나 사용자를 발견하면 서버 중재자에게 신고할 수 있습니다. 사용자 또는 게시물의 펼침 메뉴에서 “신고”를 클릭하면 신고 대화상자가 열립니다. 여기에서 신고 이유를 작성할 수 있으며, 작성하는 것이 좋습니다. 문제가 된 게시물을 첨부하여 맥락을 설명할 수 있습니다. 상대방의 행동이 상대 서버의 규칙도 위반한다면 그 서버의 중재자에게 신고를 전달하도록 선택할 수도 있습니다.
