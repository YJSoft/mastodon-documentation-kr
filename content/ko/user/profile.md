## 프로필 꾸미기 {#appearance}

{{< figure src="assets/profile-card.png" width="75%" caption="표시 이름, 아바타, 헤더와 짧은 자기소개가 표시된 프로필 카드" >}}

**환경설정** &gt; **공개 프로필** &gt; **프로필 편집**에서 다른 사람에게 보이는 프로필을 바꿀 수 있습니다.

### 표시 이름 {#name}

표시 이름은 다른 사용자에게 주소보다 앞에 표시됩니다. 기본적으로 최대 30자까지 설정할 수 있습니다.

### 자기소개 {#bio}

자기소개는 프로필에 표시되는 짧은 소개 글입니다. 기본적으로 최대 500자까지 입력할 수 있습니다. 링크는 실제 길이와 관계없이 모두 23자로 계산되므로 글자 수를 아끼려고 단축 URL을 사용할 필요는 없습니다. 오히려 단축 URL 사용은 권장하지 않습니다.

### 아바타 {#avatar}

아바타는 게시물 옆에 표시되는 아이콘으로, 시각적으로 나를 나타냅니다. 최대 2MB의 WEBP, PNG, GIF 또는 JPG 이미지를 올릴 수 있습니다. 이미지는 400x400 크기로 축소됩니다.

### 헤더 {#header}

헤더는 프로필 상단에 표시되는 배너 이미지이며, 팔로우 목록과 계정 디렉터리의 프로필 카드에도 나타납니다. 최대 2MB의 WEBP, PNG, GIF 또는 JPG 이미지를 올릴 수 있습니다. 이미지는 1500x500 크기로 축소됩니다.

## 프로필 표시 {#flags}

프로필에 특정 표시를 설정하여 마스토돈을 어떻게 사용하는지 다른 사람에게 알릴 수 있습니다.

{{< figure src="assets/bot-flag.png" width="50%" caption="자동화된 계정으로 표시된 프로필의 모습" >}}

### 잠긴 계정 {#locked}

계정을 잠그면 두 가지가 달라집니다.

* 새 팔로워가 자동으로 승인되지 않고, 직접 승인해야 합니다.
* 팔로우가 즉시 승인되지 않는다는 것을 알리기 위해 다른 사람에게 자물쇠 아이콘이 표시됩니다.

### 봇 계정 {#bot}

봇 표시를 켜면 프로필에 봇 아이콘이 추가됩니다. 이 아이콘은 계정이 자동화된 작업을 수행하거나 사람이 직접 확인하지 않을 수 있음을 알립니다. 다른 소프트웨어에서는 봇 프로필을 다르게 처리할 수도 있지만, 현재 마스토돈에서는 시각적인 표시로만 사용합니다.

### 프로필 디렉터리 {#discoverable}

프로필 디렉터리 등록에 동의하면 프로필을 둘러보는 기능을 통해 다른 사람이 내 프로필을 발견할 수 있습니다.

## 프로필 메타데이터 {#fields}

프로필 메타데이터는 쉽게 훑어볼 수 있는 추가 정보를 프로필에 넣는 방법입니다. 총 4개의 행에 항목 이름과 값을 지정할 수 있습니다. 예를 들면 다음과 같습니다.

| 항목 | 내용 |
| :--- | :--- |
| 나이 | 25 |
| 국가 | 독일 |
| 대명사 | he/him |
| 웹사이트 | https://example.com |

무엇을 넣을지는 자유입니다. 내용에 멘션, 해시태그, 커스텀 이모지, 링크를 포함할 수 있습니다.

### 링크 인증 {#verification}

중앙 기관 없이 신분증 기반 인증이나 파란 인증 표시를 제공할 수는 없습니다. 하지만 마스토돈은 프로필에 넣은 링크를 상호 확인하여 실제로 해당 링크의 소유자인지 증명할 수 있습니다. 이미 알려져 있고 신뢰할 수 있는 개인 홈페이지라면 신분증 인증을 대신할 수 있는 수단이 됩니다.

{{< hint style="info" >}}
마스토돈은 직접 호스팅할 수 있으므로, 사람들이 이미 신뢰하는 자신의 도메인에서 마스토돈을 운영하는 것이 신원을 확인하는 가장 좋은 방법입니다.
{{< /hint >}}

프로필 메타데이터에 HTTPS 링크를 넣으면 마스토돈은 해당 웹페이지에 특별한 `rel=me` 속성으로 내 마스토돈 프로필을 가리키는 링크가 있는지 확인합니다. 링크가 있다면 소유자로 확인되어 해당 링크 옆에 인증 체크 표시가 붙습니다. 마스토돈도 프로필 메타데이터의 링크에 `rel="me"`를 붙입니다. 링크는 다음과 같은 형태입니다.

```html
<a href="https://social.example.com/@username" rel="me">Follow me on Mastodon!</a>
```

웹페이지의 head 영역에 직접 넣을 수도 있습니다.

```html
<link href="https://social.example.com/@username" rel="me">
```

#### 링크 인증 조건 {#validation-criteria-for-verified-links}

마스토돈은 다음 조건에서 프로필 필드의 링크 인증을 진행합니다.

- 프로필 필드의 값은 **반드시 HTTPS로 시작하는 링크**여야 합니다. 다른 값이나 다른 종류의 링크는 처리하지 않습니다. 특히 일반 HTTP 링크는 안전하지 않고 전송 중 공격자가 내용을 바꿀 수 있으므로 처리하지 않습니다.
- 4.0부터는 **IDN 정규화 후에도 호스트 이름이 바뀌지 않아야 합니다**. 이는 ASCII 문자와 매우 비슷하게 보이는 유니코드 문자를 섞는 동형이의어 공격을 막기 위한 것입니다. 예를 들어 `U+0061`(영문 소문자 “a”)과 `U+0430`(키릴 문자 소문자 “а”)은 거의 같아 보이지만 완전히 다른 문자입니다. 이러한 외형의 유사성을 악용하여 사람을 속일 수 있습니다.

그런 다음 마스토돈은 링크가 가리키는 웹페이지를 가져와 다음 기준을 만족하는 링크를 찾습니다.

- 가져온 페이지에는 `rel="me"` 속성이 있는 `a` 또는 `link` 태그가 하나 이상 있어야 합니다.
  - 해당 요소 중 하나의 `href` 속성이 내 마스토돈 프로필 URL과 같아야 합니다.
- `rel="me"` 링크가 없다면 *첫 번째* 링크를 확인하며, 그 링크의 `href` 값이 내 마스토돈 프로필 URL로 리디렉션되어야 합니다. 이는 rel-me를 사용하지 않고 단축 URL을 사용하는 웹페이지를 제한적으로 지원하기 위한 것입니다.
- HTTP 응답은 1MB를 넘으면 안 됩니다.
- 링크는 HTML 응답에 직접 포함되어야 하며 JavaScript를 실행하지 않아도 접근할 수 있어야 합니다.

**이러한 링크는 `iframe` 안에 있으면 안 됩니다.** `iframe` 안에 있으면 링크는 현재 웹페이지가 아니라 그 안에 삽입된 외부 웹페이지에 있는 셈입니다. 일부 블록 기반 CMS는 블록 요소를 iframe으로 감싸기 때문에 이 조건으로 인해 인증이 되지 않을 수 있습니다.

{{< hint style="info" >}}
웹페이지에 rel-me 링크를 추가한 *뒤에* 프로필을 저장하세요! 인증 절차는 프로필을 저장할 때 시작되며 완료까지 시간이 걸릴 수 있습니다. rel-me 링크를 넣었는데 인증되지 않는다면 프로필에서 링크를 지우고 저장한 다음, 링크를 다시 추가하고 저장해 보세요.
{{< /hint >}}

### 저자 표시 {#attribution}

글이나 작품을 만드는 사람이라면 기사, 블로그 글, 기타 저작물이 마스토돈과 연합우주에서 공유될 때 마스토돈 계정을 저자로 표시하고 링크할 수 있습니다. 작품을 게시하는 웹사이트의 HTML에 `fediverse:creator` 태그를 넣으면 됩니다.

**환경설정** &gt; **공개 프로필** &gt; **인증** &gt; **저자 표시**로 이동하여 기사 HTML의 head 영역에 복사해 넣을 코드를 확인하세요. 코드는 다음과 같은 형태입니다.

```html
<meta name="fediverse:creator" content="@username@social.example.com">
```

다음으로 **나를 저자로 표시할 수 있는 웹사이트** 필드에 `example.com`과 같은 발행 사이트의 도메인을 추가하세요. 링크 미리보기에 허위로 저자로 표시되는 것을 방지하는 설정입니다.

허용한 웹사이트에 게시한 콘텐츠가 연합우주에서 공유되면 내가 저자로 표시되며, 저자 정보에 내 마스토돈 프로필 링크가 포함됩니다.
