## 텍스트 {#text}

텍스트 입력란에서 게시물의 본문을 작성할 수 있습니다. 기본 글자 수 제한은 500자입니다.

### 링크 {#links}

{{< figure src="assets/compose-links.png" width="50%" caption="링크는 http(s)://로 시작해야 하며 길이와 관계없이 23자로 계산됩니다" >}}

게시물에 넣는 링크는 `http://` 또는 `https://`로 시작해야 합니다. 링크는 실제 길이와 관계없이 모두 23자로 계산되므로 글자 수를 아끼기 위해 단축 URL을 사용할 필요가 없습니다. 오히려 단축 URL 사용은 권장하지 않습니다.

### 멘션 {#mentions}

{{< figure src="assets/compose-mentions.png" width="50%" caption="로컬 및 원격 사용자에 대한 멘션 자동 완성" >}}

`@alice@example.com`처럼 전체 주소를 입력하면 사용자를 멘션할 수 있습니다. `@word`를 입력하면 사용자명이 `word`인 로컬 사용자가 있을 경우 해당 사용자에 대한 멘션으로 해석됩니다. 글자 수 제한에는 사용자명 부분만 포함되고 도메인은 포함되지 않습니다.

### 해시태그 {#hashtags}

{{< figure src="assets/compose-hashtags.png" width="50%" caption="사용 빈도와 함께 자동으로 제안되는 해시태그" >}}

`#hashtag`를 사용하면 해당 해시태그를 검색하는 누구나 게시물을 발견할 수 있습니다. 해시태그에는 문자, 숫자, 밑줄을 사용할 수 있지만 숫자로만 구성할 수는 없습니다.

### 커스텀 이모지 {#emoji}

{{< figure src="assets/compose-custom-emoji.png" width="50%" caption="선택창에서 사용할 수 있는 다양한 커스텀 이모지" >}}

각 서버는 Slack이나 Discord처럼 커스텀 이모지를 제공합니다. `:thounking:`과 같은 단축 코드를 입력하거나, 작성창의 이모지 얼굴을 클릭하고 “커스텀” 분류를 살펴보면 사용할 수 있습니다. 표준 유니코드 이모지도 찾아보고 검색할 수 있습니다.

이모지 피부색은 이모지 검색창 옆의 선택 도구에서 바꿀 수 있습니다.

## 첨부 {#attachments}

게시물에는 파일이나 투표 중 하나를 첨부할 수 있습니다.

### 파일 {#media}

{{< figure src="assets/compose-media-attachment.png" width="50%" caption="첨부 미디어의 미리보기와 추가 옵션을 위한 편집 버튼이 표시된 새 게시물" >}}

사진이 겹쳐진 아이콘을 클릭하면 게시물에 파일을 첨부할 수 있습니다. 다음 파일을 지원합니다.

* **이미지**(PNG, JPG, HEIF, WEBP, AVIF): **최대 16MB**. 이미지는 830만 화소(3840x2160 이미지에 해당하는 크기)로 축소됩니다. 게시물 하나에 최대 4장까지 첨부할 수 있습니다.
* **움직이는 GIF**(GIFV): **최대 16MB**. 소리가 없는 MP4로 변환됩니다. GIF의 크기는 100만 화소(1280x720) 미만이어야 합니다. 소리가 없는 MP4 및 WebM 파일도 올릴 수 있으며, 클라이언트에서 움직이는 GIF처럼 반복 재생됩니다. 게시물 하나에 움직이는 GIF를 하나만 첨부할 수 있습니다.
  * 정지된 GIF에도 움직이는 GIF와 같은 제한이 적용됩니다. 이러한 이미지를 올릴 때 문제가 발생하면 지원하는 다른 이미지 형식으로 변환해야 합니다.
* **동영상**(MP4, M4V, MOV, WebM): **최대 99MB**. 최대 비트레이트 1300kbps, 프레임 속도 120fps의 H.264 MP4로 변환됩니다. 게시물 하나에 동영상을 하나만 첨부할 수 있습니다.
* **오디오**(MP3, OGG, WAV, FLAC, OPUS, AAC, M4A, 3GP): **최대 99MB**. V2 VBR(약 192kbps) 방식의 MP3로 변환됩니다. 게시물 하나에 오디오 파일을 하나만 첨부할 수 있습니다.

#### 미디어 편집 {#edit}

{{< figure src="assets/edit-media.png" caption="미디어 설명(대체 텍스트)을 추가하거나 미리보기 이미지의 초점을 지정하는 미디어 편집 화면" >}}

첨부 파일 미리보기의 “편집” 링크를 클릭하면 미디어 설명을 추가하거나 초점을 바꿀 수 있는 창이 열립니다. 필수는 아니지만 미디어에 어떤 내용이 있는지 간략하게 설명하는 것이 좋습니다. 설명은 미디어를 불러오지 못했을 때 표시되며, 화면 읽기 프로그램 등 보조 기술에서도 사용됩니다. 초점 지정도 선택 사항이지만 미리보기가 16:9 비율이 아닐 때 더 보기 좋게 표시하는 데 도움이 됩니다.

### 투표 {#polls}

{{< figure src="assets/compose-polls.png" width="50%" caption="하루 뒤에 종료되는 단일 선택 투표를 포함한 새 게시물" >}}

막대그래프 아이콘을 클릭하면 게시물에 투표를 첨부할 수 있습니다.

* 선택지는 최대 4개까지 추가할 수 있습니다. 각 선택지는 최대 25자입니다.
* 기본값은 하나만 고르는 단일 선택 투표입니다. 라디오 버튼을 클릭하면 여러 항목을 고를 수 있는 체크박스 방식으로 바뀝니다.
* 투표 종료 시간은 5분, 30분, 1시간, 6시간, 1일, 3일, 7일 뒤로 설정할 수 있습니다.

## 게시물의 공개 범위와 개인정보 보호 {#privacy}

게시물마다 네 가지 공개 범위 중 하나를 선택할 수 있습니다. [기본 공개 범위를 설정](../preferences#posting)할 수 있으며, 작성 중인 게시물은 본문 위의 버튼으로 “공개 범위 및 상호작용” 대화상자를 열어 공개 범위를 바꿀 수 있습니다.

{{< figure src="assets/post-visibility.png" width="70%" caption="게시물의 공개 범위 옵션이 표시된 ‘공개 범위 및 상호작용’ 대화상자" >}}

아래 표는 공개 범위에 따라 게시물이 어디에 표시되는지 보여 줍니다. “공개 피드”에는 검색 결과, 유행, 실시간 피드가 포함됩니다.

| 설정 | 공개 피드 | 프로필 | 홈 피드 |
| :--- | :--- | :--- | :--- |
| 공개 | 표시 | 표시 | 표시 |
| 조용한 공개 | 숨김 | 표시 | 표시 |
| 팔로워 | 숨김 | 팔로워와 멘션된 계정에 표시 | 팔로워와 멘션된 계정에 표시 |
| 개인 멘션 | 숨김 | 멘션된 계정에 표시 | 멘션된 계정에 표시 |

{{< hint style="info" >}}
“팔로워” 또는 “개인 멘션” 게시물의 직접 링크(고유 링크)에는 해당 게시물을 볼 수 있는 사용자가 로그인한 경우에만 접근할 수 있습니다. 브라우저에서 고유 링크를 열면 게시물이 작성된 서버로 이동하며, 그 서버에는 내 계정이 없을 수도 있습니다.  
내 계정이 있는 서버에서 게시물을 열려면 해당 서버에 로그인하고, 검색창에 링크를 붙여 넣은 뒤 “마스토돈에서 URL 열기”를 선택하세요.
{{< /hint >}}

각 공개 범위에 대한 자세한 설명은 다음과 같습니다.

### 공개 {#public}

기본 옵션입니다.

* 로그인하지 않아도 누구나 고유 링크에서 게시물을 볼 수 있습니다.
* 앱의 공개 타임라인과 내 프로필에 게시물이 표시됩니다.
* 팔로워의 홈 피드에 게시물이 전달되고, 멘션된 사용자에게는 알림으로 전달됩니다.
* 다른 사람의 홈 피드로 부스트할 수 있습니다.

### 조용한 공개 {#unlisted}

다음 차이점을 제외하면 공개와 같습니다.

* 마스토돈의 실시간 피드나 둘러보기에 게시물이 표시되지 않습니다.
* 계정에서 전문 검색을 허용했더라도 검색 결과에 게시물이 표시되지 않습니다.

이 옵션의 이전 이름은 “Unlisted”(미등재)였습니다.

### 팔로워 {#followers}

게시물이 전달되는 범위를 더 제한하는 옵션입니다.

* 나를 팔로우하는 계정과 게시물에 멘션된 계정만 볼 수 있습니다.
* 앱에서는 팔로워와 멘션된 사용자에게만 게시물이 표시됩니다.
* 팔로워의 홈 피드에 게시물이 전달되고, 멘션된 사용자에게는 알림으로 전달됩니다.
* 작성자 자신만 부스트할 수 있습니다.

{{< hint style="warning" >}}
팔로워 전용 게시물의 열람 대상을 실질적으로 제한하려면 **“새 팔로워 자동 승인” 옵션을 꺼야 합니다**. 그렇지 않으면 누구나 나를 팔로우하여 이전 게시물을 볼 수 있습니다.
{{< /hint >}}

{{< hint style="danger" >}}
마스토돈의 공개 범위는 계정 전체가 아니라 게시물마다 적용됩니다. **이미 공개한 게시물을 나중에 비공개로 바꾸는 방법은 없습니다.**
{{< /hint >}}

### 개인 멘션 {#private}

멘션한 사용자에게만 게시물을 보냅니다.

* 게시물에 멘션된 계정만 볼 수 있습니다.
* 앱에서는 멘션된 사용자에게만 게시물이 표시됩니다.
* 멘션된 사용자에게 알림으로 전달됩니다. 홈 타임라인에는 표시되지 않습니다.
* 부스트할 수 없습니다.

이 옵션의 이전 이름은 “Specific people”(특정 사용자)이었습니다.

{{< hint style="warning" >}}
**노출되면 위험하거나 민감한 정보는 개인 멘션으로 공유하지 마세요.** 마스토돈은 Signal이나 Matrix 같은 암호화 메신저가 아니므로, 발신자와 수신자 서버의 데이터베이스 관리자가 내용을 열람할 수 있습니다.
{{< /hint >}}

## 답글의 표시 범위 {#replies}

팔로워가 나와 답글을 받는 사람을 모두 팔로우할 때만 해당 팔로워의 홈 피드에 내 답글이 표시됩니다.

다음 사항도 알아두세요.

* `@mention`으로 시작하는 새 게시물은 답글로 간주되지 **않으므로** 모든 팔로워의 홈 피드에 표시됩니다.
* 답글의 공개 범위(공개, 조용한 공개, 팔로워 전용)는 홈 피드에 표시되는지 여부에 영향을 주지 **않습니다**.
* 공개 게시물에 팔로우 중인 해시태그가 포함되면 답글인지와 관계없이 홈 피드에 표시됩니다.
* 다른 연합우주 소프트웨어는 누구에게 보낸 답글인지와 관계없이 모든 답글을 홈 피드에 표시할 수 있습니다.

## 콘텐츠 경고 {#cw}

{{< figure src="assets/status-cw.png" width="50%" caption="콘텐츠 경고를 펼친 게시물과 가려진 첨부 이미지" >}}

마스토돈은 다른 소셜 네트워크에서는 낯설 수 있는 콘텐츠 경고 기능을 제공합니다. 콘텐츠 경고를 넣으면 게시물 본문이 기본적으로 접히고 경고 문구만 표시됩니다. 이메일 제목이나 “더 보기” 구분선과 비슷합니다. 게시물에 요약이나 주제를 붙이거나, 긴 글을 접거나, 본문에 앞서 맥락이나 배경을 설명하는 데 사용할 수 있습니다.

미디어를 첨부하면 “미디어를 민감한 콘텐츠로 표시” 체크박스가 나타납니다. 선택하면 미디어가 기본적으로 흐릿한 미리보기 뒤에 가려집니다. 게시물에 콘텐츠 경고(CW)를 추가하면 첨부 미디어도 자동으로 민감한 콘텐츠로 표시됩니다.
